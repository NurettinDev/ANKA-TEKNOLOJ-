# ANKA TEKNOLOJİ — Bireysel Çalışmalar

Bu repo, ANKA TEKNOLOJİ ekibindeki kişilerin bireysel çalışmalarını paylaşması için hazırlanmıştır.

## Ekip kuralı

- Her ekip üyesi çalışmalarını yalnızca kendi adıyla oluşturulmuş klasöre yükler.
- Başka bir ekip üyesinin klasöründeki dosyaları değiştirmeyin, silmeyin veya taşımayın.
- Her çalışma için kendi klasörünüzün içinde ayrı ve açıklayıcı isimli bir alt klasör oluşturun.
- Çalışmanıza, ne yaptığınızı ve gerekiyorsa nasıl çalıştırılacağını anlatan kısa bir açıklama ekleyin.
- Kişisel bilgi, şifre, erişim anahtarı veya gizli dosya yüklemeyin. Bu repo herkese açıktır.

## GitHub üzerinden doğrudan dosya yükleme

1. GitHub hesabınızla giriş yapın ve bu repoyu açın.
2. Kendi adınızın olduğu klasöre girin.
3. **Add file → Upload files** seçeneğini kullanın.
4. Çalışmanızın dosyalarını veya çalışma klasörünü sürükleyip bırakın.
5. Yaptığınız yüklemeyi anlatan kısa bir commit mesajı yazın.
6. **Commit directly to the main branch** seçeneğiyle **Commit changes** düğmesine basın.

Örnek düzen:

```text
Beyza/
├── README.md
└── ilk-calisma/
    ├── README.md
    └── calisma-dosyalari
```

## Erişim ve yetkilendirme

Doğrudan yükleme için repo sahibi tarafından GitHub hesabınıza yazma yetkisi verilmiş olması ve gönderilen katkıda bulunan (collaborator) davetini kabul etmiş olmanız gerekir. Yalnızca repoyu görebilmek, dosya yükleme yetkisi vermez.

Repo sahibi kişileri **Settings → Collaborators → Add people** bölümünden GitHub kullanıcı adlarıyla davet edebilir.

GitHub yazma yetkisini klasör bazında sınırlandırmaz. Herkesin yalnızca kendi klasöründe çalışması bu reponun ekip kuralıdır.
