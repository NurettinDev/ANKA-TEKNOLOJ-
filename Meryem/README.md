# Meryem — Bireysel Çalışmalar

Bu klasör Meryem adlı ekip üyesinin bireysel çalışmaları içindir.

## Çalışma yükleme

1. Bu klasördeyken **Add file → Upload files** seçeneğini açın.
2. Dosyalarınızı veya açıklayıcı isimli çalışma klasörünüzü sürükleyip bırakın.
3. Kısa bir commit mesajı yazıp doğrudan **main** dalına kaydedin.

Her ayrı çalışma için bu klasörün içinde bir alt klasör kullanın. Çalışmanın amacını ve gerekiyorsa nasıl çalıştırılacağını anlatan kısa bir README ekleyin.

**Ekip kuralı:** Yalnızca kendi klasörünüzde çalışın; diğer kişilerin dosyalarını değiştirmeyin, silmeyin veya taşımayın.

Doğrudan yükleme için repo üzerinde yazma yetkiniz olmalıdır. Ayrıntılar için [ana yönergeleri](../README.md) okuyun.
